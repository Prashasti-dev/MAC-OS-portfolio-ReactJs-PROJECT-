> A fully interactive, macOS-inspired developer portfolio built with React — featuring draggable terminal windows, an embedded Spotify player, a CLI interface, and a live resume viewer.<img width="1912" height="862" alt="Screenshot 2026-04-13 231657" src="https://github.com/user-attachments/assets/d50b7a43-512d-4542-903a-b0dea18dc099" />

This portfolio reimagines the traditional developer portfolio as a **macOS desktop experience**. Instead of a static webpage, visitors interact with a fully functional simulated desktop environment — complete with a dock, draggable windows, and real app-like experiences for each section.

Tech Stack

- **React.js** — Core UI framework
- **SCSS** — Custom styling with macOS-inspired design tokens
- **react-rnd** — Draggable and resizable window components
- **react-console-emulator** — CLI terminal emulation
- **Spotify Embedded API** — Music player integration
- **Markdown / Typewriter Effect** — Animated text rendering for the developer profile

   🖱️ How It Works

1. The user lands on a **macOS-style desktop** with a scenic wallpaper.
2. A **dock** at the bottom contains icons for: GitHub, Notes, Gmail, Spotify, PDF Resume, Links, Calendar, and Terminal.
3. Clicking any dock icon **opens a new draggable terminal window** on the desktop — styled like macOS Terminal with traffic light buttons.
4. Windows can be **moved, resized, and layered** freely across the desktop.
5. The **CLI terminal** accepts commands and displays developer profile info in a code-art style.
6. The **Spotify window** plays actual music via the Spotify embedded player.<img width="1908" height="865" alt="Screenshot 2026-04-13 232911" src="https://github.com/user-attachments/assets/03e8d6b4-cbec-4751-92ba-11a1e4cafe46" />
